# Natsukashi UI
*A nostalgic feeling android experiance designed after 2000s feature phones*

## What is this?:
Natsukashi UI is both a custom home screen launcher and a full suite of apps that make your android based flip phone really feel like one straight out of 2005! This is by far the fastest launcher built for android powered flip phones.

## Current Status:
### Working:
- Main launcher homescreen/Standby screen
- Quick apps page with numerical shortcuts to commonly used apps
- Music player app with Artist and Album support as well as a shuffle play feature
- Transport app for public transport navigation (Auckland, NZ region only (Auckland Transport))
- Notes app with both normal notes and daily "Journal" notes
- Calendar app
- Settings app for both device settings and launcher settings
### Not Working/Planned:
- Custom web browser
- File manager app
- Photo gallery app
- Maps app with navigation support
